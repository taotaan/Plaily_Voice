# 🖥️ Plaily 3D Avatar Frontend

Frontend web dashboard for the **Plaily (ปลายลี่)** 3D Virtual Assistant. Built with React 19, Vite, Three.js (TalkingHead WebGL Renderer), and MediaPipe Vision.

For complete system architecture and documentation, see [Root README.md](../README.md).

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open `http://localhost:5173` in your browser (Ensure backend is running at `http://localhost:8000`).
